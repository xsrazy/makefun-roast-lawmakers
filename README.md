One satirical sentence roasting lawmakers who would regulate AI, crypto, or the internet but cannot convert a file to PDF, entered for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
